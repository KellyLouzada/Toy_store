Toy Store – ServiceNow Application

📌 Overview

Toy Store é uma aplicação desenvolvida na plataforma ServiceNow com o objetivo de simular o gerenciamento de uma loja de brinquedos. O sistema permite organizar produtos, registrar pedidos e estruturar informações de forma eficiente dentro da plataforma.

Este projeto foi desenvolvido como parte de um bootcamp de desenvolvimento em ServiceNow, com foco em modelagem de dados, criação de aplicações e automação de processos.

⸻

🚀 Funcionalidades
	•	Cadastro e gerenciamento de produtos
	•	Registro e acompanhamento de pedidos
	•	Organização de dados por meio de tabelas customizadas
	•	Criação de formulários para entrada e visualização de informações
	•	Estruturação de lógica de negócios dentro da plataforma

⸻

🛠 Tecnologias e Recursos Utilizados
	•	Plataforma ServiceNow
	•	Modelagem de dados (Tables & Fields)
	•	Formulários e List Views
	•	Lógica de negócios e estrutura de aplicação

⸻

🎯 Objetivo do Projeto

O objetivo deste projeto foi praticar o desenvolvimento de aplicações na plataforma ServiceNow, explorando conceitos como organização de dados, criação de interfaces e estruturação de processos dentro de um cenário de negócio.

⸻

📚 Aprendizados

Durante o desenvolvimento deste projeto foi possível aprofundar conhecimentos em:
	•	Estrutura de aplicações na plataforma ServiceNow
	•	Modelagem de dados e organização de informações
	•	Criação de formulários e gerenciamento de registros
	•	Implementação de lógica de negócios
